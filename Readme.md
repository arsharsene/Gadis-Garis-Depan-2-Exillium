## How to Install

1. Backup **LangPackageTableCnData.bytes** in this folder:

bilibili Game
└─ GF2_Exilium
└─ Games
└─ GF2_Exilium_Data
└─ LocalCache
└─ Data
└─ Table
└─ LangPackageTableCnData.bytes

2. Replace it with the Indonesian translation file.
3. Done!
